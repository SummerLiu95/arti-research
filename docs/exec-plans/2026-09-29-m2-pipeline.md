## 背景

完成 TASKS M2：从公开数据源采集到人工复核入库的完整离线研究管道，这是交付的核心。

## 完成内容

- **T2.1** `pipeline/ingest/SOURCES.md`：数据源清单（SEC EDGAR submissions JSON + 10-K 全文）+ 合规自查（对照验收清单 03 条逐项打勾）+ 歧义/冲突/过期处理原则
- **T2.2** `pipeline/ingest/`：httpx 采集 SEC 公开 JSON，快照落盘 `pipeline/snapshots/<date>/`，每个快照带 meta.json（url、publisher、retrieved_at、sha256）；10-K URL 从 submissions 索引动态解析。已实际抓取 NVIDIA 最新 10-K（1.9MB）
- **T2.3** `pipeline/extract/`：Pydantic schema（关系类型/方向/状态/摘录≤400字/locator/置信度）+ 双模式——fixture（默认，无凭据可复现）与 llm（OpenAI structured output，产出同样过 schema）
- **T2.4** `pipeline/resolve/`：别名表精确匹配消歧（中英别名、大小写不敏感），未匹配进 unresolved 交人工
- **T2.5** `pipeline/review/`：草稿逐条人工确认 → 入库，关系关联快照 meta 生成证据；幂等（重复运行不重复插入）
- **T2.6** `tests/test_pipeline.py`：6 个边界测试（摘录超长/置信度越界/未知类型拒绝、别名大小写、未注册实体、fixture 质量门），全部通过
